# Future Product Roadmap & Intelligence Expansion — Radient AI

This document details the planned milestones, feature expansions, and expert-informed intelligence pathways for Radient AI.

---

## 1. Roadmap Milestones

```
  NEAR-TERM                   MID-TERM                  LONG-TERM
  ┌────────────────────────┐  ┌──────────────────────┐  ┌────────────────────────┐
  │ • Additional Modalities│  │ • Agent Engine       │  │ • Multi-Hospital       │
  │ • Expanded Benchmarks  │  │ • Firestore State    │  │ • Multi-Specialty      │
  │ • Synthetic Cases      │  │ • Analytics Engine   │  │ • Global Expert Net    │
  └────────────────────────┘  └──────────────────────┘  └────────────────────────┘
```

### Near-Term Milestones
*   **Additional Modalities:** Implement support for Mammography, Nuclear Medicine (NM), PET/CT, and Interventional Radiology (IR).
*   **Expanded Benchmark Datasets:** Partner with regional hospitals to compile aggregate, non-identifiable benchmark operational targets.
*   **More Synthetic Cases:** Design pre-configured mock scenarios (e.g. "Post-Holiday Scan Backlogs", "Equipment Maintenance Outages").
*   **More A2A Agents:** Decouple Data Quality, Operational Benchmarking, and Financial Audit components into independent remote A2A services.

### Mid-Term Milestones
*   **Vertex AI Agent Engine Deployment:** Transition from custom Cloud Run A2A instances to Google's fully managed Agent Engine and Agent Runtime systems.
*   **Firestore State Persistence:** Save historical scenario runs, user ratings, and selected optimizations directly to Cloud Firestore.
*   **Benchmarking Analytics Engine:** Develop automated statistical anomaly detection to identify operational drift automatically.

### Long-Term Milestones
*   **Multi-Hospital Operations Support:** Support complex corporate hospital chains with centralized operational overview dashboards.
*   **Multi-Specialty Expansion:** Expand agentic optimization frameworks beyond Radiology to Emergency Departments (ED), Operating Rooms (OR), and Outpatient Clinics.
*   **Global Expert Network:** Create a collaborative platform where operations experts can publish operational playbooks as plug-and-play grounding datasets.

---

## 2. Collaborating Healthcare Domain Experts
To ensure Radient AI's calculations and suggestions reflect real-world clinical operations, future intelligence expansion will be guided by:

*   **Imaging Directors & Radiology Managers:** Informing shift allocations, technologist licensing constraints, and machine prep time requirements.
*   **Staff Technologists:** Detailing workloads, burnout thresholds, shift-change fatigue factors, and cross-training realities.
*   **Hospital CFOs & Revenue Cycle Leaders:** Aligning financial savings metrics, scanner ROI models, billing compliance, and premium call-back labor budgets.
*   **Operational Excellence Consultants:** Documenting industry best practices and hospital throughput optimization methodologies.
